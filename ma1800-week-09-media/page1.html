the web expands

After the first website went live at CERN in 1991, the World Wide Web quickly began to spread beyond the research community. A key moment came in 1993 with the release of NCSA Mosaic, one of the first widely used graphical web browsers.

Mosaic made the web easier to use by allowing images and text to appear together on the same page. Its popularity helped introduce the web to a much wider audience and contributed to the rapid growth of websites during the 1990s.

In 1994, Tim Berners-Lee founded the World Wide Web Consortium (W3C), an organisation that develops open standards for web technologies. The W3C continues to contribute to standards including HTML and CSS.
